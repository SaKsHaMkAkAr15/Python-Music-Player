# Music Player in python

## What it does
A desktop Music Player application built with Python that allows 
users to play, pause, skip and control volume of MP3 songs from 
a local playlist.

## Features
- Play and pause songs
- Next and previous track controls
- Volume control with smooth slider
- Scrollable playlist with click to play
- Displays currently playing song name
- Album art placeholder
- Opens centered on any screen size
- Modern dark UI with CustomTkinter

## What I learned
- Building desktop GUI apps with Tkinter and CustomTkinter
- Playing audio files with Pygame
- Reading files from folders using OS module
- Connecting UI components to functions
- List comprehension for filtering files
- Screen size detection and window centering

## How to run
1. Make sure Python is installed
2. Install required libraries:
pip install pygame customtkinter
3. Add MP3 files inside a folder called songs
4. Run this command:
python app.py

## Tech used
- Python
- Tkinter / CustomTkinter
- Pygame
- OS module
